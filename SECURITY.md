# Security

## Reporting a problem

If you find a security problem in the V0 Visualizer desktop app or its update feed, please email **support@hasanjws.com** with "Security" in the subject, rather than posting it in public. Include what you found, the app version (Settings > About) and the steps to reproduce it.

You will get a reply within a few days. Please give us a reasonable time to fix the problem before you share details.

## How updates are protected

The app installs an update only when its signature matches the public key built into the app. A release's `.sig` files hold those signatures. An update that fails the check is not installed.

## Supported versions

Only the newest release receives fixes. The app updates itself, so keeping it running is enough to stay current.
